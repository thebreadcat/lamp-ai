Install Lamp

One script does the work: downloads Lamp, installs Ollama, picks a model for your RAM, sets up HTTPS, and starts the server.

Open Terminal and paste:

curl -fsSL https://raw.githubusercontent.com/thebreadcat/lamp-ai/main/setup/install.sh | bash

Open PowerShell and paste:

irm https://raw.githubusercontent.com/thebreadcat/lamp-ai/main/setup/install.ps1 | iex

Or download install.bat from GitHub and double‑click it.

For a dedicated home device (Pi 4/5):

curl -fsSL https://raw.githubusercontent.com/thebreadcat/lamp-ai/main/setup/first-boot.sh | sudo bash

Creates a Wi‑Fi setup hotspot, installs Ollama, and serves at lamp.local. See the Pi setup guide.

  • Detects RAM and pulls a sensible Ollama model
  • Creates HTTPS automatically (microphone works on phones)
  • Shows a QR code on the login screen for same‑Wi‑Fi devices
  • You create a name + 4‑digit PIN — then start chatting

How it works

  1. Run the installer Wait a few minutes while Ollama and Lamp download.
  2. Open Lamp in your browser On this computer: https://localhost:7700. On your phone: scan the QR on the login screen.
  3. Accept the security warning once Lamp uses a self‑signed certificate on your home network so voice input works on phones.
  4. Create the admin account Add family members later in Settings. Everyone gets their own PIN and apps.

Common questions

Do I need to know Git or Python?

No. The installer handles downloads, Ollama, HTTPS, and starting the server. You only need a Mac, PC, or Pi with internet for the first run.

Does my data leave the house?

Chat and apps run against a model on your machine (via Ollama). Nothing is sent to Lamp’s servers — there aren’t any.

Why does my phone warn about the certificate?

Browsers require HTTPS for the microphone off‑localhost. Lamp generates a private certificate for your Wi‑Fi. Tap through the warning once per device — that’s normal for self‑hosted home software.

How do I update Lamp?

When an update is available, admins see a banner in Lamp. Stop the server, then run python3 lamp.py --update from your Lamp folder (or ./setup/update.sh). Your data in ~/.workshop is kept. Restart Lamp when it finishes.

What hardware do I need?

A Mac or PC with 8 GB+ RAM works well. For an always‑on home hub, a Raspberry Pi 4 (4 GB+) or Pi 5 is ideal — see the Pi requirements.
